# 十种真实扫描物体的抓取测试

在当前服务器使用 MuJoCo、官方 GR3 + FDH-6 模型、原生相机安装位姿和 M2T2 官方权重进行模拟。每次桌面放一个物体，共 10 种；每种初始偏航为 0°、45°、90°，共 30 个固定场景。不是十个物体同时堆放，也不是随机分布上的统计成功率。

正式结果目录：`outputs/benchmark10_com`。运行结束后查看其中的 `report.md`、`summary.json`、`results.csv` 与 `contact_sheet.png`。每个场景的相机 RGB-D、目标点云、模型原始预测、手部候选、规划诊断、执行轨迹、接触日志和终态分别保存在 `trials/<物体>_yaw<角度>/`。无候选时也保留原始网络输出与失败原因。

## 已完成结果

本节为历史旧筛选实现 `outputs/benchmark10_com` 的结果。后续定位到 M2T2 上游目标掩码筛选的括号错误，当前默认修正；原 19 次无候选不能直接归因于模型识别能力。复现本节旧结果需加 `--legacy-m2t2-filter`。修复后的独立对照与头部扫描见 [头部扫描与点云融合](头部扫描与点云融合.md)。

30 次均已完成，**成功 2/30（6.7%）**，涉及 2/10 种物体。6 次进入物理执行，只有下列 2 次通过完整验收；没有把 2/6 当成总体成功率。

| 物体与初始朝向 | 保持期质心最小升高 | 保持时间 | 对向承力接触比例 | 最大穿透 |
|---|---|---|---|---|
| 糖果盒，45° | 13.65 cm | 2 s | 100% | 1.886 mm |
| 蜡笔盒，45° | 16.60 cm | 2 s | 99% | 1.588 mm |

两种物体均为 1/3 个朝向成功，其余八种物体均为 0/3。失败分布：**19 次无有效模型候选、5 次路径不可行、4 次未稳定提起或滑落**；本轮没有超时、流程错误或执行碰撞。不能把规划成功当成抓取成功。

`contact_sheet.png` 固定按物体和三个朝向显示全部 30 个实际终态，绿色为成功，红色为失败；`successful_cases.png` 仅放大两个成功终态。成功案例的另行录制回放保存在 `demos/candy_box_yaw045/grasp.mp4` 和 `demos/crayon_box_yaw045/grasp.mp4`，不增加测试分母。

## 固定协议

- 资产来自同一固定提交的 Google Scanned Objects MuJoCo 转换仓库；保留原始尺寸、纹理与 32 块凸分解碰撞网格。
- 所有场景使用相同 XY 放置区域、相机参数、M2T2 权重/阈值/采样配置、手部 TCP 映射、闭手控制、力矩限制、IK 与碰撞容差。物体质量是显式仿真假设，见清单，未在看过结果后调参。
- 每次 M2T2 保留最多 24 个去重源位姿，并生成两侧闭合对称候选。规划器按顺序找出首个能完成预抓取、接近和提起路径的候选，只执行一次。执行失败后不重置重试，不按物理执行结果挑选最佳候选。
- 目标由 RGB-D 前景分割获得，在固定任务区域内选最大连通分量；不读取模拟器标签构造位姿。单物体的仿真真值只用于碰撞允许列表和结果评估，避免长物体的扫描原点偏移使评估关联失败。
- 升高量按**质心**计算，避免物体翻转导致扫描参考原点升高。要求完整 2 秒保持期内升高至少 10 厘米、脱离桌面，至少 90% 采样同时具有拇指和其他手指的承力接触，且穿透受 3 毫米阈值限制。
- 无前景、无模型候选、不可达、碰撞、滑落和超时均计入 30 次总分母，不能只对成功进入执行的案例计算成功率。每次独立子进程，180 秒超时。

## 复现

```bash
cd gr3_grasping
python3 scripts/fetch_assets.py
uv sync --locked --extra dev --extra perception --extra m2t2
.venv/bin/python scripts/fetch_m2t2_weights.py
.venv/bin/python scripts/benchmark_objects.py \
  --manifest configs/benchmark10.yaml --legacy-m2t2-filter --output outputs/my_benchmark10 --jobs 2
```

批测过程中就会更新汇总文件；未完成时 `complete=false`，分母仍显示全部配置场景。输出目录若已有测试清单，脚本会要求改用新目录，保留已有证据。`jobs` 只控制 CPU 子进程并发数，不修改任何抓取参数。

单独复现某场景并录视频：

```bash
.venv/bin/gr3-grasp simulate \
  --config outputs/benchmark10_com/trials/crayon_box_yaw045/config.yaml \
  --backend m2t2 --arm right --legacy-m2t2-filter --output outputs/my_crayon_replay
```

## 如何解读

这是当前 CPU PointNet++ 参考算子、单视角 RGB-D、固定 FDH-6 刚体坐标映射和闭手控制链路的结果，不是 M2T2 原论文或官方 CUDA 环境的模型成功率。源模型是双指夹爪模型，其接触置信度没有经过 FDH-6 质量校准。没有在测试失败后调低阈值、换几何位姿、加物体绑定或放宽验收标准。

固定基座、理想重力补偿、假设相机内参与手部接触参数仍然限制迁移。本次没有验证实物相机、全身平衡、十物体堆叠分割或真机执行。

首轮扩大工作区时误把机器人手纳入前景，已停止并标记为无效调试记录：`outputs/benchmark10_roi_pilot`。随后沿用扫描原点高度的探索轮保存在 `outputs/benchmark10`；正式汇总仅使用完整重跑的 `outputs/benchmark10_com`，不将不同轮的成功案例合并。
